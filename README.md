# Number Guessing Game

## Project Title
Number Guessing Game Using Python

## Introduction
The Number Guessing Game is a simple Python-based mini project.
In this game, the computer generates a random number between 1 and 100.
The player has to guess the correct number within a limited number of attempts.

## Objective
The main objective of this project is to understand Python programming concepts such as:
- Variables
- Loops
- Conditional statements
- User input
- Exception handling
- Random number generation

## Features
- Generates a random number between 1 and 100.
- Allows the player to guess the number.
- Provides hints if the guess is too high or too low.
- Limits the number of attempts.
- Handles invalid inputs.
- Displays the correct number when the game ends.

## Technology Used
- Programming Language: Python 3
- Platform: GitHub

## How to Run the Program
1. Install Python 3.
2. Download the file `number_guessing_game.py`.
3. Open a terminal or command prompt.
4. Run the following command:

   python number_guessing_game.py

5. Follow the instructions displayed on the screen.
